## Описание проекта

Адаптивная версия многостраничного HTML/CSS-сайта вымышленного интернет-магазина механических клавиатур. Проект выполнен на основе КР №1 без использования CSS-фреймворков.

## Самостоятельные доработки

- Собственная визуальная концепция и цветовая схема на CSS-переменных.
- Бейджи «Хит», «Новинка», «Скидка» и БЭМ-модификаторы карточек.
- Хлебные крошки на внутренних страницах.
- Блоки отзывов и FAQ на `<details>`.
- Вторая таблица: сравнение комплектаций.
- Sticky-фильтры каталога и sticky-блок на странице товара.
- Кнопка «Наверх» (`position: fixed`).
- Модальное окно на `<dialog>` с формой.
- Адаптивное карточное представление таблицы на мобильных экранах.
- Responsive images с `srcset`, `sizes` и `picture`.
- Доступность: skip-link, видимый `:focus-visible`, подписи полей, `aria-current`, `aria-label`.
- Публикация проекта через GitHub Pages.
